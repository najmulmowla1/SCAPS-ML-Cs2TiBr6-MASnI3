# Dataset

The primary SCAPS-1D dataset (18,225 configurations) is cited at:

**Mendeley Data (Version 1):** https://doi.org/10.17632/4fgnm4wftb.1

Download the archived dataset from Mendeley Data. Supply its path to `--dataset`.
The notebook originally used an Excel file named `DATASET INITIALIZATION(1).xlsx`.

The dataset is **not included** in this GitHub code archive. The repository does not
include the SCAPS-1D executable or independently runnable SCAPS input files.
